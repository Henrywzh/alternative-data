SOURCES & METHOD

OpenRouter: public per-model daily tokens, grouped by the model's lab. Estimated spend multiplies prompt and completion tokens by each model's listed OpenRouter price; discounts, free tiers and caching are not seen. ARR annualises a month; the current month is a nowcast from the days observed so far.

Ramp Tokenomics: weekly API token spend and volume by model from businesses using Ramp Token Spend Management, which imports usage and billing from connected providers. It is a sample that grows as customers connect, not all of Ramp's AI spend and not a lab's revenue. Weeks are spread evenly over their seven days to make calendar months.

Monthly estimates: a month with every day observed is a total; the latest month is a run-rate, the days seen scaled to the whole month, and is drawn lighter. The two sources measure different buyers, so compare shares and direction rather than adding the dollars.
