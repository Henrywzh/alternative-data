## 海航额外提供的字段

海航月度 PDF 比当前四字段 schema 更丰富，可作为第二阶段 optional metrics：

| 字段 | 中文定义 | 用途 |
|---|---|---|
| `rtk` | 收入吨公里 | 客货综合运输量 |
| `atk` | 可利用吨公里 | 客货综合运力 |
| `rftk` | 收入货邮吨公里 | 货运需求 |
| `aftk` | 可利用货邮吨公里 | 货运运力 |
| `cargo_tonnes` | 货运及邮运量 | 实物货量 |
| `freight_load_factor_pct` | 货邮载运率 | 货运供需匹配 |
| `overall_load_factor_pct` | 总体载运率 | 客货综合载运效率 |
| `fleet_added` | 当月引进飞机数 | 机队扩张 |
| `fleet_retired` | 当月退出飞机数 | 机队收缩 |
| `fleet_total` | 月末运营飞机数 | 运力基础 |
| `new_route_events` | 新开航线事件 | 网络扩张事件流 |

不要因为某一家航司缺少其中某个字段而删除整家公司；应采用 optional columns，并在 `metric` / `event_type` 中保留来源粒度。

## 推荐的 derived signals

第一批最有用的是：

1. `RPK YoY - ASK YoY`：需求增长是否超过运力增长。
2. 客座率同比变化：运力投放是否过量。
3. 国际 RPK 占比、国际 ASK 占比：国际航线恢复和网络暴露度。
4. 货运收入吨公里占 RTK 比例：货运对集团运输量的贡献。
5. 货邮载运率变化：货运需求相对运力的强弱。
6. `RPK / passengers`：平均航段长度 proxy；不是票价或 yield。
7. 机队净增速：`fleet_added - fleet_retired`。
8. 新开国际／地区航线事件：作为事件流，不要伪装成连续时间序列。

月度运营公告通常没有真实票价、RASK、CASK、燃油成本或利润。票价 yield、燃油成本、租赁成本和利润率应从季度／年度报告另建财务数据表，不要从月度 RPK 反推。
