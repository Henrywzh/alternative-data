**公开可用：**

| 数据 | 来源 | 频率 | 获取方式 |

## 二、HBM / 高带宽内存 — AI GPU 的另一半

HBM3/HBM3e 是 AI 芯片内存瓶颈。SK Hynix 几乎独占，Samsung 和 Micron 在追。

**公开可用：**

| 数据 | 来源 | 频率 | 获取方式 |
|------|------|------|----------|
| SK Hynix 月营收 | ~~韩国 KOREA-IX 披露系统~~ | ~~月~~ | 【已修正】"KOREA-IX" 疑似虚构——未查到此披露系统。SK Hynix **不公布月度营收**，实际按**季度**披露（已核实其最新为 2026 Q1 结果），符合韩国无台湾式月营收强制披露制度的事实。韩国真实的公开披露系统是 **DART**（金融监管院电子披露系统），但也只有季度财报，没有月度数字 |
| Samsung DS 营收 | Samsung IR（分部的季度） | 季 | 但可用韩国海关填补月度（未逐条验证） |
| 韩国半导出口 | Korea Customs HS 8542 | 月 | 【已核实】已用真实 UN Comtrade 请求验证：HS **854232**（"电子集成电路—存储器"）是真实可查询的细分税则号（2025年1月韩国出口额约$4.77B），已有关税框架，细化到memory子类 |
| DDR5/HBM 现货价 | DRAMeXchange（TrendForce公告） | 周/月 | 【已修正】"公开新闻稿免费"夸大——实际现货价格数据库需要付费"DRAM Platinum"会员，免费部分只是零星的叙述性博客文章，不构成可用于流水线的系统性周/月价格数列 |
| NAND 现货价 | 同上 | 周/月 | 同上，同样被会员墙限制 |

**逻辑：** 韩国海关 IC 出口 (HS 8542) 细分中有"memory"子类目（HS 854232，已核实真实可查）。DRAMeXchange 的周度价格趋势**不是**免费可系统获取的——如需量×价反推营收方向，需另寻付费数据源或接受叙事性博客文章的不完整覆盖。

## 四、中国 Semiconductor — 最不透明也最有趣

### 4.1 国产替代进度 — 海关是最干净的信号

中国海关总署 HS 8486（半导体设备）的月度进出口数据可以告诉你：

```
设备总进口 ↓ + 来自日/荷的进口 ↑ = 还是依赖进口
设备总进口 ↓ + 中国国内设备商收入 ↑ = 国产替代真的在发生
设备总进口 ↑ + 来自管制国的进口 ↓ = 转口贸易/灰色通道
```

- **来源:** ~~海关总署（http://43.248.49.97/）可部分查询~~ 【已修正】该 IP 地址已实测**完全无法访问**（HTTP/HTTPS 均 20 秒超时无响应），并非"较差但可部分查询"，而是当前从本环境完全不可达
- **频率:** 月频（未能核实，因来源不可达）
- **难度:** 网站较差，需要定时爬取——且实测显示可能需要大陆内网络环境才能访问，非单纯的"网站差"问题

### 4.2 招标数据（Fab 备机信号）

中国 fab 在新设备采购时会走公开招标流程，信息在：

- **中国机电产品招标网** (www.chinabidding.com) —【已修正】实测 **Cloudflare 521**（源站宕机），当前完全不可达，不是"数据量大需清洗"的问题，而是网站本身连接失败
- **中国采购与招标网** (www.chinabidding.cn) —【已修正】网络层面可达，但实测返回**混淆的反爬 JS 挑战页面**，不是真实内容；这是原文未提及的一个真实抓取障碍，不只是"关键字搜索爬取"那么简单
- 各省招标网（未逐一验证）

**可以提取的信号：**
- SMIC 北京/深圳/上海 fab 设备采购→产能扩建节奏
- CXMT（长鑫存储）DRAM 设备采购→内存扩张
- YMTC（长江存储）NAND 设备采购→3D NAND 层数升级
- **价值:** 领先官方公告 1-2 个季度 —【未核实】此提前量为叙述性推测，没有可追溯来源支撑，引用前需自行验证

**获取方式:** 关键字搜索爬取（"光刻机"、"刻蚀机"、"CVD"、"SMIC"），~~免费但数据量较大，需清洗~~ 两个主要招标网站中一个已宕机、一个有反爬 JS 挑战，实际难度比"数据量大需清洗"高得多，可能需要专门的反爬工程投入或改用各省招标网逐一评估。

### 4.3 SMIC 产能利用率反推

SMIC 的季度营收是公开的（688981.SH），但利用率不公布。

**近似公式：**

```
晶圆出货量 ≈ 营收 / 均价（每个制程档次）
产能利用率 ≈ 出货量 / 设计产能
```

设计产能可以从招标数据中的设备采购量 + 每台设备的 WSPM（Wafer Starts Per Month）推算。

### 4.4 地方政府补贴公告

中国半导体 fab 高度依赖地方政府补贴。补贴信息通常出现在：
- 地方发改委/经信委网站
- 各地方政府的 WeChat 公众号
- 上市公司公告

**可以识别：** 某地级市宣布"支持集成电路产业园"→约 6-12 个月后 fab 开始采购设备。【未核实】此时滞同样是叙述性推测，无可追溯来源，引用前需自行验证。

## 五、招聘数据（LinkedIn + Boss直聘）

这是一个跨行业的 leading indicator。

**可获取的信号：**

| 公司 | 岗位类型 | 意义 |
|------|----------|------|
| TSMC Arizona | EUV 工程师/厂务 | 美国 fab 进度 |
| TSMC Kumamoto | 设备工程师 | 日本 fab 进度 |
| SMIC | 设备工程师/工艺整合 | fab 扩张 |
| ASML | 客户支持工程师 | 设备安装量 → 后续服务收入 |
| Naura/AMEC | 研发工程师 | 国产替代招聘 |
| Nvidia AMD Intel | 芯片设计 | 产品 pipeline |

**获取方式：**
- LinkedIn API (受限) / 网页爬取（反爬严）
- Boss直聘 (zhipin.com) — 国内最全，可按公司/地区/职位搜索
- 猎聘 (liepin.com)
- Indeed / Glassdoor（全球）

**注意：** 招聘数据是"数量"信号，不是"方向"信号——招聘多不代表公司在进步，也可能是 turnover 高。

## 六、专利数据

专利申请趋势可以揭示技术路线方向：

| 领域 | 相关分类 | 价值 |
|------|----------|------|
| GAA (Gate-All-Around) | H01L29 / H01L21 | 3nm以下制程进展 |
| Hybrid Bonding | H01L25 / H01L24 | 先进封装/3D堆叠 |
| EUV 光刻 | G03F7 / H01L21 | 制程微缩 |
| SiC / GaN | H01L29 / H01L21 | 第三代半导体 |
| HBM 封装 | G11C5 / H01L25 | 内存堆叠 |

**来源：**
- USPTO / Google Patents (全球免费)
- CNIPA (中国，可搜索但批量有限制)
- Lens.org (免费，大量分析功能)

**价值：** 专利数量爆发 ≈ 研发投入加大。但要注意：中国有些企业"为专利而专利"，需要结合专利引用/技术分类做质量筛选。

### 一句话判断

> AI/semi 制造对**散户或小团队**来说数据确实不透明，但对**有技术能力的量化研究者**来说，海关贸易 + 招标 + 招聘 + 专利四件套已经可以在大部分维度上构建有效的高频 proxy。你最大的优势是已经跑通了海关数据 pipeline——只需要在分类粒度和覆盖范围上再推一层。
