
The branch diverged long ago and `main` has moved 280 commits since. That is the

## Approach: cherry-pick onto fresh branches, do not rebase

Rebasing 82 commits across 280 commits of drift is avoidable. The decisive fact:

> The three new-module lines (`us_census_trade_data`,
> `semiconductor_high_frequency_data`, HKEX event study) touch **zero** of
> main's 342 changed files — all new paths.

They cherry-pick cleanly today. Bundling them with the conflicted work would
hold clean code hostage.

Each PR below starts from current `origin/main`:

```bash
git fetch origin
git switch -c <pr-branch> origin/main
git cherry-pick <commits>
```
